# Security and privacy

The workbench has no backend, authentication, analytics, API secrets, or automatic publishing. Text and image exports are generated in your browser. Treat downloaded plans as your own files; they can contain article details, destination URLs, and relationship disclosures.

The hosted page still uses GitHub Pages infrastructure. Local generation does not imply that the hosting provider receives no ordinary website requests. The app itself sends no brief, pin copy, or images to an API.

Saved JSON is size-limited and validated. Restored links are rebuilt from the validated brief, and review states reset to Draft. SVG text is escaped. CSV cells beginning with spreadsheet formula markers receive a protective prefix. ZIP file names are generated internally and reject unsafe paths.

For a security concern, use the contact route on [Mona’s Media](https://monasmedia.com/). Do not include credentials, customer records, or private plans in public issues. This demo is not a confidential client storage system.
